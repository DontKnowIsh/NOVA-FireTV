**NOVA 1.2.0 – first release of the new NOVA**

A cinematic, remote-first Jellyfin client for Amazon Fire TV (Fire OS).

**Highlights**
- New home and library pages: hero previews, poster grids with an A–Z bar, sorting, age filters and "Surprise me"
- Live TV (IPTV) with your own M3U or Xtream login: category pills, channel cards, live preview and favourites, in your chosen theme
- Optional request and download management through Seerr, Radarr, Sonarr and qBittorrent
- Themes, avatars, kids lock, PIN-protected delete, open-on-start-up and navigation sounds
- Fresh for every user: no built-in codes, works with any library layout

**Install:** download `NOVA-FireTV.apk` below and see the README for steps. `NOVA-FireTV-source.tar.gz` is the full source this APK was built from (GPL-2.0).
