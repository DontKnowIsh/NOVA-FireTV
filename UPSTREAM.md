# Upstream source

NOVA Fire TV is an unofficial derivative/fork of the official Jellyfin Android TV application.

- **Project:** Jellyfin Android TV
- **Upstream repository:** https://github.com/jellyfin/jellyfin-androidtv
- **Base version:** v0.19.10
- **Upstream licence:** GNU GPL v2.0
- **Target for this customization:** Amazon Fire TV / Fire TV Stick

The build workflow checks out the upstream v0.19.10 source and applies the NOVA customization files and patch script. The release workflow also packages the patched source tree corresponding to the built APK.

NOVA Fire TV is not an official Jellyfin release and is not endorsed by the Jellyfin project.
